## 1. 项目概述

### 1.1 背景

晋跨通定位"让山西制造，一站卖全球"。根据市场调研结论，山西跨境电商企业大部分没有自己的独立站，存在"刚需已觉醒、供给未饱和"的窗口期。第一版不做重 SaaS，而是先做一个**轻量官网 + 产业带出海渠道地图**，作为品牌展示与获客漏斗入口。

### 1.2 第一版目标

1. 建立"晋跨通"品牌官网，讲清楚"我们是谁、帮谁、做什么"。
2. 上线**产业带出海渠道地图**：覆盖四大类产业带每类 Top10 企业（共约 40 家），收录其海外渠道（企业官网/英文站/跨境独立站/B2B 平台店铺），并标注验证状态。
3. 建立 **4 套行业特色模板体系**：按企业类别（工业制造 / 农副食品 / 新材料新能源 / 文化工艺）提供差异化独立站模板，符合海外用户使用习惯。
4. 对已有独立站的企业，**参考其现有站点进行进一步优化**（保留品牌资产与 SEO 沉淀，改进转化路径与体验短板）。
5. 以"待认领"占位卡片作为**销售线索库**，为后续 SaaS 业务导流。
6. 完成 Cloudflare Pages 部署，实现低成本、高可用的全球访问。

### 1.3 成功标准（第一版）

- 首页首屏可完整传达定位与 Slogan；
- 覆盖四大类产业带每类 Top10 企业（共约 40 家），数据 100% 可维护（集中式数据文件）；
- 4 套类别模板全部落地，可通过数据字段切换模板；
- 已有独立站的企业完成现状分析并输出优化方案（模板化重建或渐进优化）；
- 所有页面 Lighthouse 性能 ≥ 90、SEO ≥ 90（移动端）；
- 通过 Cloudflare Pages CI 自动部署上线；
- 上线首月收集 ≥ 50 条"待认领"线索（通过认领表单/联系方式）。

## 3. 技术选型

### 3.1 技术栈

| 类别 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | Next.js 15+（App Router） | 当前主流，静态导出友好，生态完善 |
| 语言 | TypeScript（strict） | 类型安全 |
| 样式 | Tailwind CSS v4 | 原子化、快速、纯净 |
| 组件 | 自研轻量组件（不引入重型 UI 库） | 保持纯净 |
| 数据 | TypeScript 数据文件（`src/data/*.ts`） | 集中维护，类型约束 |
| 部署 | Cloudflare Pages（静态导出） | 全球 CDN、免费额度、自动 HTTPS |
| 代码托管 | GitHub（CI 联动 Cloudflare Pages） | — |

### 3.2 部署方案分析

| 方案 | 实现 | 优点 | 缺点 | 适用 |
| --- | --- | --- | --- | --- |
| **A. 静态导出（推荐）** | `next.config.ts` 设 `output: 'export'` | 最纯净、部署最简单、无需 Node 运行时、性能最佳 | 无 SSR/Server Actions/中间件；动态功能受限 | 第一版官网 + 静态数据地图 |
| B. OpenNext on Cloudflare | `@opennextjs/cloudflare` 适配器 | 支持完整 Next.js（SSR/API/中间件） | 复杂度高、构建链路重 | 需要动态功能的 v2 |

**决策：第一版采用方案 A（静态导出）。** 理由：

1. 第一版为纯内容展示站，全部数据为静态 TS 文件；
2. 静态导出部署在 Cloudflare Pages 上最稳、最快、成本最低；
3. 为 v2 保留升级路径（改造为 OpenNext 或迁移 API 到 Cloudflare Workers 均可）。

### 3.3 静态导出的关键约束（开发时注意）

- `next/image` 需设置 `unoptimized: true`，或直接使用普通 `<img>` + 懒加载；
- 动态路由须使用 `generateStaticParams` 全量生成；
- 不可使用 Server Actions、middleware、rewrites/redirects（如确需 redirects，可用 Cloudflare Pages `_redirects`）；
- 环境变量在构建期注入（`NEXT_PUBLIC_*`）。

## 4. 模板体系设计（行业特色模板）

> 核心原则：**每类企业的独立站采用适用该类企业特色的模板，并符合海外用户的使用习惯**。模板按企业类别差异化，通过数据字段 `template` 指定，第一版内置 4 套模板。

### 4.1 模板分类与适用场景

| 模板 | 适用类别 | 目标人群 | 模板定位 |
| --- | --- | --- | --- |
| T1 工业制造模板 | 传统制造与工业品（玻璃、法兰、水泵、金刚石、不锈钢、铸造件等） | 海外 B2B 采购商/工程商 | 工厂实力 + 产品规格 + 询盘转化 |
| T2 农副食品模板 | 特色农副与食品（小杂粮、林果、调味品、肉制品、菌类） | 海外进口商/D2C 消费者 | 产地故事 + 安全认证 + 健康理念 |
| T3 科技新材料模板 | 新材料、新能源与电子产品（LED、光机电、半导体材料、碳纤维等） | 海外技术采购/工程师 | 技术参数 + 应用场景 + 研发能力 |
| T4 文化工艺模板 | 文化工艺品（推光漆器、潞绸、木器、砂器、青铜） | 海外收藏家/礼品渠道 | 文化叙事 + 工艺美学 + 收藏价值 |

### 4.2 各模板特色与海外习惯要点

**T1 工业制造模板（B2B 侧重）**
- 首屏：厂房/生产线实景大图 + 核心产品轮播；
- 板块：公司实力（车间、设备、检测能力）、产品中心（规格表 + 可下载 PDF + 询盘）、认证墙（ISO/CE/UL 等）、客户案例与全球分布地图；
- 转化：多功能询盘表单（询价/定制/OEM/索取报价）+ Email/WhatsApp 直连；
- 海外习惯：B2B 买家看重资质、产能、MOQ、交期、认证，信息密度高但结构清晰；
- 参考风格：欧美工业设备厂商 / Alibaba 国际站优质供应商主页。

**T2 农副食品模板（D2C/B2B2C）**
- 首屏：产地风景/产品故事大图 + "产地直供"卖点；
- 板块：产品故事（产地、工艺、溯源）、产品系列（精美实拍 + 成分/营养）、食品安全认证（有机/HACCP/FDA）、品牌故事（晋商文化）；
- 转化：询盘/商城 + 订阅优惠 + 社媒联动（Instagram/Facebook）；
- 海外习惯：强调天然、有机、可追溯、健康，视觉有食欲感，内容营销（食谱/产地故事）增强信任；
- 参考风格：欧美精品食品 D2C 品牌。

**T3 科技新材料模板（B2B 技术驱动）**
- 首屏：产品渲染图/应用场景 + 技术标语；
- 板块：技术参数表（数据密集）、应用场景（行业解决方案）、研发能力（实验室/专利/认证）、文档下载（Datasheet/白皮书）；
- 转化：技术咨询表单、样片/样品申请；
- 海外习惯：工程师主导采购，重视规格数据、可下载技术文档、第三方测试报告；
- 参考风格：欧美科技硬件厂商官网。

**T4 文化工艺模板（D2C 精品）**
- 首屏：艺术感大图 + 品牌故事；
- 板块：工艺过程（匠人故事、制作流程）、产品图鉴（高质感实拍 + 细节放大）、文化价值（非遗/传承）、限量与定制；
- 转化：精品询盘/预订、画廊式浏览、收藏咨询；
- 海外习惯：重视文化叙事、艺术价值、收藏与礼品场景，慢视觉、留白设计；
- 参考风格：欧美手工艺精品店 / 高端画廊。

### 4.3 通用框架（4 套模板共用）

- Header/Nav：Logo、Products、About、Certifications、Contact（符合欧美信息架构习惯）；
- 信任区：认证图标、客户评价、合作品牌、出口数据；
- Footer：联系方式、社媒、Privacy Policy、Terms & Conditions；
- 移动端优先；模板骨架支持中英双语切换（第一版默认英文内容为主，中文文案可切换）。

### 4.4 海外用户使用习惯规范（全模板通用）

1. **语言与本地化**：默认英文界面；统一英式/美式拼写；尺寸单位（inch/cm、lbs/kg）、货币（USD/EUR）按目标市场本地化；
2. **信任要素**：真实工厂/产品实拍图、第三方认证、客户评价、可核验的地址与电话；
3. **转化路径**：B2B 以询盘表单/Email/WhatsApp 为主（海外不用 QQ/微信）；B2C 支持 PayPal/主流信用卡；
4. **合规**：Cookie 弹窗（GDPR）、Privacy Policy、Terms & Conditions 页面；
5. **性能与体验**：页面加载 < 3s、图片懒加载、清晰的信息层级；
6. **SEO**：英文关键词落地、语义化 H1、结构化数据（Organization/Product）、sitemap.xml；
7. **社媒联动**：Instagram/Facebook/LinkedIn 等欧美主流社媒入口。

### 4.5 已有独立站的参考与优化流程

> 规则：**无论该企业有没有现成独立站，均覆盖其 Top10 展示位**；若已有独立站，必须参考现有站点做进一步优化。

| 步骤 | 动作 | 输出 |
| --- | --- | --- |
| 1. 现状盘点 | 抓取并分析现有独立站：技术栈（Wappalyzer/BuiltWith）、内容、SEO、转化路径 | 站点现状报告 |
| 2. 资产提取 | 保留品牌资产：Logo、色系、产品图、文案、域名 | 资产清单 |
| 3. 差距分析 | 对照类别模板 + 海外习惯规范做 Gap Analysis | 差距清单 |
| 4. 优化方案 | 输出两档：A) 模板化重建（迁移至晋跨通模板）；B) 渐进优化（保留现有站，仅改转化/信任/移动端短板） | 优化方案书 |
| 5. 交付确认 | 与企业确认后执行；若企业暂不迁移，先以"渠道地图 + 优化建议"形式交付 | 执行与确认记录 |

## 5. 信息架构与页面清单

```
/
├── /                          首页（品牌落地页）
├── /industrial-belts          产业带总览
├── /industrial-belts/[slug]   产业带详情（代表企业 + 渠道地图）

├── /about                     关于晋跨通（服务、团队、联系方式）
└── /claim                     企业认领 / 联系表单页
```

### 5.1 首页 `/`

- Hero：Slogan"让山西制造，一站卖全球" + CTA（查看产业带 / 认领企业）；
- 数据看板：出口额、平台卖家、备案企业等关键数据；
- 三大综试区卡片；
- 产业带矩阵（四大类入口）；
- 样板产业带精选（祁县玻璃、定襄法兰、怀仁/应县陶瓷、吕梁农特）；
- 服务介绍（建站 / 合规 / 海外仓 / 代运营）；
- 底部：联系与备案信息。

### 5.2 产业带总览 `/industrial-belts`

- 全部产业带卡片（分类过滤）；
- 每张卡片：名称、区位、代表产品、企业数、综试区归属。

### 5.3 产业带详情 `/industrial-belts/[slug]`

- 产业带介绍（产品、区位、出口数据）；
- 代表企业列表（引用企业数据）；
- 该产业带出海渠道概况。

### 5.4 企业渠道地图 `/companies`

- 企业卡片列表 + 筛选（按产业带、按渠道标签）；
- 四级标签：`企业官网` / `英文站` / `跨境独立站` / `B2B 平台店铺` / `未验证待认领`；
- 每卡显示核心渠道链接 + 验证状态。

### 5.5 企业详情 `/companies/[slug]`

- 企业简介 + 渠道地图（多个链接分组展示）；
- 验证状态说明（"已核验"或"待认领"）；
- CTA：认领 / 纠错入口。

### 5.6 关于与认领 `/about`、`/claim`

- 服务范围、合作方式、园区/协会合作；
- 联系表单（第一版用第三方表单服务或 mailto 提交）。

## 7. 数据设计

> 数据集中放在 `src/data/`，使用 TypeScript 类型约束，替换数据后重新构建部署即可更新站点。

### 7.1 模板定义（`src/data/templates.ts`）

```ts
// 模板定义：描述每套类别模板的元信息与设计规范
export type TemplateKey = 't1-industrial' | 't2-agri-food' | 't3-tech-material' | 't4-craft';

export interface TemplateMeta {
  key: TemplateKey;          // 模板标识，如 't1-industrial'
  name: string;              // 模板名，如 '工业制造模板'
  category: 'manufacturing' | 'agri-food' | 'new-material' | 'crafts'; // 对应企业类别
  audience: string;          // 目标人群，如 '海外 B2B 采购商'
  designSpec: string;        // 设计规范（色系/字体/布局要点）
  keySections: string[];     // 核心板块清单
}
```

### 7.2 产业带数据结构（`src/data/industrial-belts.ts`）

```ts
// 产业带定义：单一职责，只描述"一个产业带"
export interface IndustrialBelt {
  slug: string;              // 路由标识，如 'qi-xian-glass'
  name: string;              // 名称，如 '祁县玻璃器皿'
  category: 'manufacturing' | 'agri-food' | 'new-material' | 'crafts'; // 分类，对应模板 T1–T4
  region: string;            // 区位，如 '晋中·祁县'
  summary: string;           // 一句话简介
  products: string[];        // 代表产品
  highlights: string[];      // 亮点（出口数据、产业地位等）
  zone?: string;             // 所属综试区：太原/大同/运城
  companySlugs: string[];    // 关联企业 slug
}
```

### 7.3 企业数据结构（`src/data/companies.ts`）

```ts
// 企业定义：单家企业及其出海渠道
export type ChannelType = 'official' | 'english' | 'cross-border' | 'b2b-platform';
export type VerifyStatus = 'verified' | 'pending';

export interface Company {
  slug: string;              // 唯一标识
  name: string;              // 企业名
  beltSlug: string;          // 所属产业带
  template: TemplateKey;     // 适用模板（T1–T4），渲染时切换页面风格
  location: string;          // 所在地
  intro: string;             // 简介
  channels: {
    type: ChannelType;
    label: string;           // 如 '官网' / '英文站'
    url: string;             // 渠道链接
    note?: string;
  }[];
  verifyStatus: VerifyStatus; // 已核验 / 待认领
  claimed?: boolean;         // 是否已被企业认领
}
```

### 7.4 渠道标签体系

| 标签 | 含义 | 示例 |
| --- | --- | --- |
| 企业官网 | 自有域名中文站 | `dahuaglass.com` |
| 英文站 | 面向海外英文站 | `en.sxguanliflange.com` |
| 跨境独立站 | 支持在线交易/询盘的跨境站 | Shopify/自研站 |
| B2B 平台店铺 | 阿里国际站/亚马逊店铺等 | 平台店铺链接 |
| 未验证待认领 | 仅占位，等待企业认领 | 显示占位卡 |

### 7.5 首批 Top10 企业覆盖（共约 40 家）

**覆盖规则**：四大类产业带每类选取 Top10 企业（共约 40 家），来源包括：海关出口数据、行业榜单、综试区/园区名录、产业带协会推荐。

| 类别（模板） | 覆盖企业（示例，Top10 名单待数据核验后补全） | 已有独立站（需参考优化） |
| --- | --- | --- |
| 工业制造（T1） | 大华玻璃、冠力法兰、博达瓷业、尊屹陶瓷… | 冠力法兰 `en.sxguanliflange.com`、大华玻璃 `dahuaglass.com` 等 |

| 新材料/新能源/电子（T3） | 长治 LED、晋城光机电代表企业… | 待核验 |
| 文化工艺（T4） | 平遥推光漆器、高平潞绸代表企业… | 待核验 |

**已有独立站处理规则**：
- 无论企业有无现成独立站，均覆盖其 Top10 展示位；
- **有独立站**：完成现状分析（技术栈/内容/SEO/转化），保留品牌资产，按 §4.5 流程输出优化方案（模板化重建或渐进优化）；
- **无独立站**：直接采用对应类别模板（T1–T4）生成建站方案，作为晋跨通建站服务样板。

> 数据上线前需人工核验链接有效性；Top10 名单与核验结果以独立数据表维护；占位企业以"待认领"状态展示，作为销售线索库。

## 9. 设计规范（建议）

- **品牌色**：晋商文化基调——深青/墨色 + 金色点缀（示例：主色 `#0f3d3e` / 辅色 `#c8a24b`，最终以品牌定稿为准）；
- **字体**：中文衬线标题（如思源宋体）+ 无衬线正文（思源黑体/系统字体）；
- **风格**：简洁、可信、商务，突出"制造出海"的厚重感；
- **组件**：Card、Badge（渠道标签）、Tag（验证状态）、FilterBar、CTA 按钮等轻量自研组件；
- **模板差异化**：4 套类别模板（§4）在统一品牌基调上做差异化——工业制造偏冷峻金属感、农副食品偏温暖自然、科技材料偏简洁现代、文化工艺偏雅致留白。

> 注：品牌视觉需独立设计评审，本文档仅给出方向性建议。

## 11. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 企业链接失效 | 信任受损 | 收录前人工核验；上线后定期存活巡检（脚本/定时任务） |
| 静态导出功能受限 | 需求变更返工 | 明确范围（P0 均可在静态站实现）；v2 升级路径已规划 |
| 数据产权/企业异议 | 法律风险 | 仅收录公开信息；提供"认领/纠错"入口；标注信息来源 |
| Top10 名单口径争议 | 数据公信力受损 | 公布榜单依据（出口数据/行业榜单/园区推荐）；支持纠错申诉 |
| 已有站优化工作量超预期 | 排期风险 | 首版仅输出分析 + 方案；模板化重建按企业优先级分批交付 |
| 模板同质化 | 差异化不足 | 模板差异参数化（色系/板块/组件组合），保留自定义扩展位 |
| 域名不可用 | 品牌受阻 | 备选域名方案（见市场报告 §9）；尽早注册 |
| 线索收集不足 | 获客目标不达 | 首页/企业页多处 CTA；绑定园区/协会渠道推广 |
