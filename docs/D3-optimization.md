# 山西跨境电商已有独立站优化方案（D3）

> 版本：v0.1（2026-09-02）
> 对应 todo D3 与需求文档 §4.5 步骤 2–4（资产提取 / 差距分析 / 优化方案）。
> 依赖：B4 深度分析（本文第 2 节，数据源 `scripts/data/site-analysis.json`，2026-09-02 实测抓取）。
> 抓取范围：`src/data/companies.ts` 全部渠道 URL（30 个，成功抓取 29，`semisic.cn` 为 WAF 拦截）。

## 1. 结论摘要

- 对 40 家收录企业中**全部有渠道站点**完成技术栈 / SEO / 转化 / 语言四项逐站核验（30 URL，成功 29）。
- **技术栈**：无一使用现代建站框架；8 家 jQuery+Bootstrap 传统定制站、1 家凡科建站模板站、1 家疑似织梦(DedeCMS)（高科华烨英文站）、其余为纯静态/老旧站；**0 家使用 Shopify/WordPress 等可维护 CMS**。
- **SEO**：**结构化数据 0/30**（全部缺失）；canonical 仅 9/30；H1 仅 6/30；viewport 12/30 缺失；个别 title 严重不合格（水塔"水塔营销"4 字、宏艺无 title、朔美为主机默认页）。
- **转化**：真正询盘表单仅个别站有；WhatsApp 2/30（管家营英文站、天镇通航）；PayPal 0/30；海外社媒仅高科华烨英文站 1 家；**海外买家转化路径整体缺失**。
- **语言**：确定的中英双语站仅 3 家（冠力、管家营、高科华烨）；平遥牛肉/中科潞安/元泰 `htmlLang` 标注 en 但内容为中文，博达"BODA ARTS 英文站"实为双站同内容的 923B 跳转页——**英文站实际渗透率低于此前判断**。
- **3 个疑点站需人工复核**（朔美羊肉业主机默认页、博达双站跳转页、坚博士默认模板页），复核后"有独立站 20 家"口径可能下修。
- 据此输出两档方案：**A) 模板化重建**（适用无技术栈沉淀、站点质量差的 10 家）与 **B) 渐进优化**（适用已有内容/SEO 沉淀或集团型站点的 13 家），详见第 4 节。

## 3. 差距分析（Gap Analysis，对照 T1–T4 模板 + 海外买家习惯）

### 3.1 共性差距（影响全部 24 站）

| # | 差距 | 影响 | 对应模板能力 |
| --- | --- | --- | --- |
| G1 | 无结构化数据（JSON-LD 0/30） | 海外 Google/本地 Bing 富媒体展示缺失 | T1–T4 均内置 Organization/Product JSON-LD |
| G2 | 无海外询盘表单 / WhatsApp（2/30） | 海外买家触达后无转化出口 | InquiryForm + wa.me 直达 |
| G3 | 无 HTTPS 强制跳转（多数仍为 http 收录） | 安全信任与 SEO 降权 | Cloudflare 托管全站 HTTPS |
| G4 | 移动端适配缺失（viewport 12/30） | 移动流量流失（海外 60%+ 移动访问） | Tailwind 移动优先 |
| G5 | 无英文内容或英文仅口号（英文站 3/24） | 英文关键词不可见，Google 抓不到 | 模板中英双语内容化 |
| G6 | 无多语言切换与 GDPR Cookie 合规 | 欧盟流量合规风险 | CookieBanner + i18n 文案 |
| G7 | 页面性能（纯静态页或大体积页，如星心 210KB、管家营 170KB） | LCP 大、跳出率高 | 静态导出 + 图片懒加载 + 现代 CDN |

### 3.2 分类差距

- **T1 工业品**：双语站最像样（冠力/管家营），但缺产品参数化英文落地页与询盘闭环；博达/宏艺/坚博士站质量差。
- **T2 农副食品**：品牌展示站为主（沁州黄/紫林/水塔），无海外认证展示（欧盟有机/地理标志）、无英文产品规格页。
- **T3 新材料电子**：中科潞安/星心等为技术宣传页，无英文版、无询盘；英文站缺口最大。
- **T4 工艺非遗**：凡科模板（雅艺轩）或静态展示（唐都/潞安府），无故事化内容、无跨境渠道（仅永隆走 51sole 平台）。

## 4. 优化方案

> 两档方案对应需求 §4.5 步骤 4；**无论选哪档，第 3 节 G1–G7 共性差距中的 JSON-LD / HTTPS / 移动端为必改项**。

### 4.1 方案 A：模板化重建（迁移至晋跨通 T1–T4 模板）

**适用对象**：站点质量差（2.6 疑点站 + 纯静态无内容沉淀）+ 无英文需求矛盾（全中文）+ 无自建团队意愿。

- 朔美羊肉业（主机默认页）、博达瓷业（跳转页）、坚博士金刚石（默认模板页）、宏艺玻璃（无 title）、雅艺轩制砚（凡科模板，可迁移脱离平台绑定）。
- 潜在迁移：尊屹陶瓷、中科创源（建站平台二级域，域名不自主）、水塔醋业（title 严重不合格）。

**流程**（对应 §4.5 步骤 2–5）：

1. **资产提取**：保留 Logo、色系、产品图、文案、域名（建议同步注册英文域名）。
2. **模板选型**：按产业带选择 T1–T4，套用差异参数（色系/板块组合）。
3. **内容迁移**：产品图册/参数/资质/客户案例落到模板 8 大板块，中英双语。
4. **域名与托管**：晋跨通静态导出 + Cloudflare Pages，原域名 301 迁移保留 SEO。
5. **交付确认**：与企业确认后执行；暂不迁移则先交付"渠道地图 + 优化建议"。

**特点**：一次性重建，彻底解决技术栈/SEO/移动端/转化全部问题；**成本高（内容迁移 + 域名同步），需要企业深度参与**。

### 4.2 方案 B：渐进优化（保留现有站，仅改转化/信任/移动端短板）

**适用对象**：已有内容/SEO 沉淀或集团型站点，重建不划算。

- 良级站：管家营（补 JSON-LD/PayPal）、高科华烨（英文站补询盘闭环）、天镇通航（补英文版）。
- 中级站：大华、冠力、野山坡、沁州黄、紫林、水塔、平遥牛肉、天海、星心、元泰、潞安府、唐都、中科潞安、尊屹。
- 集团站：太钢（超大型企业，仅建议引导其英文/贸易子站优化，不纳入建站服务）。

**12 项渐进优化清单**（按优先级）：

| 优先级 | 项 | 动作 |
| --- | --- | --- |
| P0 | 1. HTTPS 强制跳转 | http→https 301（或托管到 Cloudflare 免费 SSL） |
| P0 | 2. 询盘表单 | 增加站内询盘表单（企业名/产品/数量/邮箱/WhatsApp） |
| P0 | 3. WhatsApp 直达 | 页面右下角浮动 wa.me 按钮 |
| P0 | 4. 移动端 viewport | 补 `viewport` meta + 响应式检查 |
| P1 | 5. JSON-LD 结构化数据 | 注入 Organization / Product / BreadcrumbList |
| P1 | 6. title/meta 补齐 | 按"品牌词+核心产品词+地区词"重写；水塔/宏艺必改 |
| P1 | 7. 英文关键页 | 产品页增加英文简介/参数表（最低成本起步） |
| P1 | 8. 海外社媒链接 | 页脚接入 FB/Instagram/LinkedIn（可先放官方主页） |
| P2 | 9. PayPal/线下支付说明 | 增加"Payment Methods"板块 |
| P2 | 10. GDPR Cookie 弹窗 | 面向欧盟流量的合规提示 |
| P2 | 11. 产品图与规格标准化 | 统一尺寸/白底图/参数表，利于 Google 图片搜索 |
| P2 | 12. B2B 平台联动 | 链接 Alibaba/Made-in-China 店铺（大华已有，可复制） |

**特点**：改动小、见效快、风险低，可批量交付；**保留原域名 SEO 沉淀**。

### 4.3 决策矩阵

| 判断维度 | 倾向方案 A（重建） | 倾向方案 B（渐进） |
| --- | --- | --- |
